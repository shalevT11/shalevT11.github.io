// about

I'm a Software Engineering graduate (B.Sc., Kinneret College, 2026 — GPA 91.08) focused on embedded software: bare-metal C on ARM Cortex-M, programming STM32 peripherals directly at the register level — no HAL, no shortcuts.

Before my degree I served in the Israeli Air Force as a guided-weapons technician at Ramat David Airbase, where I first fell for systems where software meets real hardware — and earned a Military Excellence Award along the way.

Beyond embedded, I've built full-stack projects in Java, Android and Node.js, managed AWS infrastructure at the Kinneret Innovation Center, and shipped a multiplayer VR simulation as my final degree project. I'm available immediately for junior embedded / software positions in northern & central Israel.

בוגר הנדסת תוכנה (מכללת כנרת, 2026 — ממוצע 91.08) עם התמחות בתוכנה משובצת: ‏bare-metal C על ARM Cortex-M, תכנות פריפריות STM32 ישירות ברמת הרגיסטרים — בלי HAL ובלי קיצורי דרך.

לפני התואר שירתתי בחיל האוויר כטכנאי חימוש מונחה בבסיס רמת דוד — שם התאהבתי במערכות שבהן תוכנה פוגשת חומרה אמיתית, וקיבלתי הצטיינות מפקד.

מעבר ל-embedded בניתי פרויקטים full-stack ב-Java, ‏Android ו-Node.js, ניהלתי תשתיות AWS במרכז החדשנות כנרת, ופיתחתי סימולציית VR מרובת-משתתפים כפרויקט הגמר. זמין מיידית למשרות ג'וניור בצפון ובמרכז.

ESP32 + Azure IoT — Predictive Maintenance‏ESP32 + Azure IoT — ניטור מנבא

★ flagshipפרויקט דגל

End-to-end IoT system — hardware to cloud: an ESP32 reads an ICM-20948 IMU over I2C at the register level, streams telemetry to Azure IoT Hub over MQTT/TLS, and a NestJS + Next.js dashboard visualizes it live with z-score anomaly detection. מערכת IoT מקצה-לקצה — מהחומרה ועד הענן: ‏ESP32 קורא חיישן IMU‏ (ICM-20948) ב-I2C ברמת הרגיסטרים, משדר טלמטריה ל-Azure IoT Hub ב-MQTT/TLS, ודאשבורד NestJS + Next.js מציג בזמן אמת עם זיהוי אנומליות z-score.

what's insideמה יש בפנים
  • Firmware (ESP-IDF, FreeRTOS): register-level I2C bring-up — bus scan, WHO_AM_I, read-modify-write wake, 14-byte burst reads (accel + gyro + temp), int16 / 2's-complement decoding.‏Firmware ‏(ESP-IDF, ‏FreeRTOS): הבאת חיישן ב-I2C ברמת הרגיסטר — ‏bus scan, ‏WHO_AM_I, ‏read-modify-write, קריאת burst של 14 בייט (תאוצה + גירו + טמפ'), פענוח int16 / 2's-complement.
  • Networking on embedded: WiFi station mode, SNTP time sync, and MQTT over TLS with SAS-token (HMAC-SHA256) auth to Azure IoT Hub.רשת על embedded: ‏WiFi station mode, סנכרון שעון ב-SNTP, ו-MQTT over TLS עם אימות SAS-token‏ (HMAC-SHA256) ל-Azure IoT Hub.
  • Engineering judgment: samples fast (5 Hz) but transmits only each window's peak — catching transients while staying inside the cloud free-tier quota.שיקול הנדסי: דוגם מהר (5Hz) אך משדר רק את ה-peak של כל חלון — תופס transients בלי לחרוג ממכסת ה-free tier.
  • Cloud + full-stack: a NestJS consumer pulls from IoT Hub → WebSockets → a Next.js / Recharts dashboard with rolling z-score anomaly detection. Green CI builds firmware + backend.ענן + full-stack: ‏NestJS צורך מ-IoT Hub ← ‏WebSockets ← דאשבורד Next.js / Recharts עם זיהוי אנומליות z-score. ‏CI ירוק בונה firmware + backend.

Bare-Metal STM32F407 Programming‏Bare-Metal STM32F407

bare-metal C‏bare-metal C

Register-level embedded C on the STM32F407G-DISC1 — no HAL, no libraries. Every peripheral configured by writing directly to memory-mapped registers, with addresses taken from the STM32F4xx reference manual. תכנות embedded ברמת הרגיסטרים על STM32F407G-DISC1 — בלי HAL ובלי ספריות. כל פריפריה מוגדרת בכתיבה ישירה לרגיסטרים ממופי-זיכרון, עם כתובות מה-Reference Manual.

what's insideמה יש בפנים
  • Five self-contained projects: GPIO output, LED toggle, pin read, button interrupts, and target-side type analysis.חמישה פרויקטים עצמאיים: פלט GPIO, הבהוב LED, קריאת פין, פסיקות כפתור וניתוח טיפוסים על ה-target.
  • Full interrupt chain implemented by hand: SYSCFG routing → EXTI edge config → NVIC enable → ISR with a volatile flag and software debounce.שרשרת פסיקות מלאה ביד: ניתוב SYSCFG ← קונפיגורציית EXTI ← ‏NVIC ← ‏ISR עם דגל volatile ו-debounce תוכנתי.
  • Extended beyond the course exercises: rotating 4-LED pattern per button press, and a custom __io_putchar for printf over ITM/SWO.הרחבות מעבר לתרגילי הקורס: סבב 4 לדים בכל לחיצה, ו-__io_putchar משלי ל-printf דרך ITM/SWO.
  • ELF analysis with GNU tools (objdump, size) and instruction-level debugging.ניתוח ELF עם כלי GNU ‏(objdump, ‏size) ודיבאג ברמת ההוראה.
